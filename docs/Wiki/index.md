# Wiki

Artigos de estudo por assunto, no formato de uma enciclopédia. Cada artigo explica o tema, mostra o que dizem os estudos e as diretrizes (com as referências em nota de rodapé) e termina com o que se faz **no HES**, com link para o item do protocolo. Os links ao longo do texto levam a outros artigos. Para procurar um termo, use a busca no topo da página.
