# Textos-padrão para o prontuário

Textos prontos para copiar e colar no prontuário eletrônico, escritos a partir dos protocolos. Clique em **Copiar texto**, cole no prontuário e complete os campos entre colchetes, como `[__/__/____]`.

Os textos não substituem a avaliação clínica: confira se a situação da paciente corresponde à descrita e ajuste o que for preciso.
